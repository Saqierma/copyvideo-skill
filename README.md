# 爆款视频结构复刻 Skill

一个用于拆解对标带货视频底层结构，并基于用户自己的产品、人物和场景生成原创短视频分镜与 AI 视频提示词的 Codex Skill。

它不是视频摘要工具，也不会直接复制原视频。Skill 只学习：

- 视频节奏与镜头功能
- 情绪曲线与画面组织
- 卖点表达顺序
- 说服与转化逻辑

原视频的具体文案、人物形象、品牌、商标、独特口头禅、具体案例和高识别度画面不会进入重构结果。

## 主要能力

1. 分析视频时长、画幅、语言、品类、受众、情绪、节奏和转化方式。
2. 按镜头拆解画面、口播、字幕、动作、产品展示、运镜、情绪和镜头作用。
3. 提炼脚本结构、情绪曲线、镜头节奏、卖点顺序与转化逻辑。
4. 建立人物、产品、场景、卖点、对白、字幕、背景和 CTA 的变量替换表。
5. 输出严格对齐原视频功能框架的原创版本。
6. 输出基于同一底层逻辑重新设计的创新故事版本。
7. 为每个镜头生成包含画面、动作、产品、运镜、光线、字幕、口播和负面要求的视频模型提示词。
8. 支持通过自然语言修改时长、镜头数、人物、场景、产品、风格和口播。
9. 支持稳定的 Markdown 表格与 JSON 输出，便于接入自动化工作流。

## 安装

```bash
mkdir -p "${CODEX_HOME:-$HOME/.codex}/skills"
git clone https://github.com/Saqierma/copyvideo-skill.git \
  "${CODEX_HOME:-$HOME/.codex}/skills/viral-video-structure-replication"
```

## 使用

向 Codex 提供：

- 对标视频文件、链接，或带时间轴的画面与转写
- 用户产品图和产品名称
- 已确认的产品卖点
- 人物、目标人群和使用场景
- 平台、时长、画幅、语言和风格要求

然后调用：

```text
使用 $viral-video-structure-replication 拆解这个对标视频，只学习底层结构，
并结合我的产品、人物和场景生成严格对齐版与延展创新版。
```

也可以要求 JSON：

```text
使用 $viral-video-structure-replication 输出 JSON，
用于接入后续 AI 图片和 AI 视频自动化工作流。
```

## 输出内容

完整任务按照固定顺序输出：

1. 原视频基础分析表
2. 原视频分镜拆解表
3. 底层结构总结
4. 变量替换表
5. 严格对齐原视频框架版
6. 延展创新故事版
7. 最终视频模型提示词

详细字段定义见 [`references/output-contract.md`](references/output-contract.md)。

## 原创性规则

- 只复用抽象结构，不复用具体表达。
- 用户产品素材和事实卖点始终优先。
- 不迁移原片品牌、商标、包装、人物或专属视觉系统。
- 不编造价格、折扣、销量、库存、认证、实验结果或产品功效。
- 无法确认的信息标记为 `未识别`、`画面推断` 或 `待确认`。
- 严格对齐版只对齐镜头功能、节奏和情绪，不逐句改写原片。
- 创新故事版必须重新组织故事因果、场景与镜头表达。
